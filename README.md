The Daily Sum renders a classic one-page newspaper front page for Tuesday, 24 November 2026 as a deterministic 1024x1024 PNG, using only the Python standard library. It draws its own 5x7 bitmap font, lays out a masthead, dateline, lead story and six more stories in two columns, and encodes the PNG by hand with zlib. No randomness, no clock and no network are involved, so every run produces byte-identical output.

## Run it

```sh
python3 main.py
```
